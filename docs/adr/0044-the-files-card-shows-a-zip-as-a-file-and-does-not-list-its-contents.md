# ファイルのカードは zip を一つのファイルとして出し、中身を一覧にしない

ファイルのカードは、zip を名前と大きさだけのファイルとして出し、中に入っているファイルを一覧にしない。中身を見たいときは、カードのボタンで Finder(Windows ではエクスプローラー)に表示して、そこから開く。zip はそれ自体が一つのファイルであり、中に入っているものを並べるのはファイルのカードの役目ではないからである。理由は読み込みの重さではないので、zip を必要な部分だけ読めるようになっても、中身の一覧は出さない。

## 見送った案

- **zip の中身をフォルダのように一覧にする表示を置く。** zip は zip という一つのファイルであり、カードがその中を開いて見せるものではない。
