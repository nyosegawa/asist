# 送信を始めたメールの下書きは、二度と送らない

下書きを送るときは、SMTP に渡す前に、送信を始めた時刻を下書きのファイルに書く。この時刻は送信が失敗したときだけ消し、時刻の残った下書きは送らない。送ったあとの下書きの削除は、ディスクの不調などで失敗することがあり、そのとき下書きが送れるまま残ると、同じメールが実在の相手にもう一度届く。送ったあとに書く記録は削除と同じ理由で失敗しうるので、二度目の送信を止められるのは、送る前に書いた記録だけである。送る前の記録を書けなければ、送らない。

## 見送った案

- **送った下書きをメモリに覚えておく。** アプリを起動し直すと忘れ、ファイルに残った下書きがまた送れる。
- **送る前に下書きを消し、失敗したら戻す。** 消した時点で下書きのカードが閉じ、失敗の理由を出す場所がなくなる。戻す書き込みが失敗すると、本文も失われる。

## 分かっている制約

- 送信の途中でアプリが終了すると、送れたかどうかに関わらず、その下書きはもう送れない。利用者は送信済みフォルダを確かめ、届いていなければ本文を新しいメールに写して送る。
- 送信が失敗したあとに時刻を消せなかったときも、その下書きは送れない。そのことはエラーの文に出る。
- 送れたかどうか分からない失敗では時刻を消す。利用者が送信済みフォルダを確かめたうえで、同じ下書きを送り直せる。
