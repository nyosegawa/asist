# 記憶は見出しも含めて会話の言語で書き、雛形を会話の11言語で持ち、整理の指示は日本語と英語だけにする

記憶(me.md、user.md、ページ、日記)は、ASIST が名前で読む見出しも含めて、会話の言語で書く。整理の Agent が使う雛形(me.md、user.md、ページ、日記)は会話の11言語すべてで持ち、ASIST はその日の会話の言語の雛形をスキルに入れる。Agent は雛形から取った見出しを一字一句そのまま写す。ASIST は、ページの最初の要約と最後の印象、日記の最後の見出しを、どの言語の形でも名前で読み、雛形が書いた見出しはどの言語のものでも検索の言葉にしない。会話の言語を変える前に書いたページも、そのまま読める。Agent が見出しを自分で訳すと、整理のたびに違う言い回しになり、雛形の見出しと Agent が中身に合わせて選んだ見出しを見分けられないからである。

整理の手順を書いたスキルの本文は、日本語と英語の二つだけにする。日本語の会話は日本語の本文を、ほかの10言語は英語の本文を使い、英語の本文は雛形の見出しを英語の雛形の形で名指しして、ほかの言語の雛形では同じ場所に同じ見出しがその言語で書いてあると伝える。英語の本文と各言語の雛形で、Agent は見出しをそのまま写し、本文をその言語で書いた(実測)。本文を訳しても写し方は良くならず、手順を変えるたびに11の本文をそろえる手間だけが増える。

## 見送った案

- **決まった見出しを、日本語の記憶では日本語、ほかの言語の記憶では英語にする。** 言語ごとの見出しの表は要らないが、ほかの言語の記憶では本文と見出しの言語が食い違い、me.md の例の見出しは Agent が訳すので整理のたびに揺れた。
- **スキルの本文も11言語で持つ。** 上に書いたとおり、写し方は変わらなかった。

## 実測

2026-10-03 に、整理の Agent の代わりに Gemini 3.8 Flash(温度 1.0)で測った。ドイツ語、ヒンディー語、韓国語の一日分の会話(新しい上司と昼を食べた話、行きつけの店での頼み方、朝は短く答えてほしいという頼み、夜の盆栽の話)を、ページも日記も無い記憶に整理させた。コマンドは実行させず、スキルの本文とその言語の雛形を渡して書いたファイルを出力させ、あとで validate.py にかけた。英語の本文で言語ごとに5回、同じ本文を Gemini でその言語に訳したもの(雛形の見出しはその言語の形で名指しした)で5回ずつ動かした。

| | 英語の本文 | 訳した本文 |
|---|---|---|
| ページの最初と最後の見出しが雛形のとおり | 29 枚中 29 | 26 枚中 26 |
| 日記の最後の見出しが雛形のとおり | 15 日中 15 | 15 日中 15 |
| user.md の見出しが雛形のとおり | 60 中 60 | 60 中 60 |
| me.md の見出しが雛形の例のどれかと同じ | 92 中 92 | 92 中 92 |
| 英語の見出し | 0 | 0 |
| validate.py が OK | 15 回中 15 | 15 回中 15 |

どちらでも、本文はその言語で書かれていた。

## 分かっている制約

- 最初の見出しより前に書いた文は、その文書にどれかの言語の要約の見出しがあれば、その見出しの下の文として読む。無ければ、かなで分かる日本語、ハングルで分かる韓国語、デーヴァナーガリーで分かるヒンディー語ではその言語の要約の見出しの下、ラテン文字で書く8言語では英語の「Summary」の見出しの下の文として読む。ラテン文字の言語どうしは、文字からは見分けられないからである。要約の見出しが無いページには、会話の言語の要約の見出しを付けるよう示す。
- ASIST が名前で読む見出し(ページの最初と最後、日記の最後)は、出したあとで言い回しを変えると、それまでの記憶に残る見出しを読めなくなる。ほかの雛形の見出しも、変えればそれまでの記憶に残る見出しが検索の言葉に戻る。
- 日本語と英語以外の雛形の文は、母語話者が読んで確かめていない。
