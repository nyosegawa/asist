# 会話ログは、保存日数を過ぎても、記憶の整理がまだ読んでいない日のファイルを消さない

会話ログは日付が変わるときに保存日数を過ぎたファイルを消すが、記憶の整理がまだ読んでいない日のファイルは、整理が読み終えるまで残す。保存日数は、整理が読み終えた日のログをいつまで残すかを決める。整理は 0 時に前日までの会話を読み、失敗した日は翌日まで読み直さない。保存日数だけで消すと、保存日数を短くした利用者で整理が何日か続けて失敗したときに、まだ読んでいない日のログが消え、その日の会話は記憶に入らないまま失われる。記憶の説明のページは、失敗した日の会話を次の整理のために残すと約束している。

## 見送った案

- **保存日数だけで消す。** 保存日数を短くした利用者で整理が続けて失敗すると、整理が読む前にその日のログが消える。

## 分かっている制約

- 整理が成功しないあいだ(Agent の CLI が入っていない、ログインが切れている、など)は、読んでいない最初の日から後の会話ログが消えずに増え続ける。設定の保存日数の説明とプライバシーポリシーに、読んでいない日は残すと書いている。
- 整理が一度も動いておらず、最初に読む日がまだ決まっていないときは、保存日数だけで消す。整理は最初に動いた日の前日から読むので、それより前のログは要らない。
