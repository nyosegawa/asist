# 会話のモデルが始める・続けるエージェントのジョブと、worktree の取り込みと破棄は、すべて確認画面でユーザーの承認を得てから行う

会話のモデルが `run_agent_task` と `continue_agent_job` でジョブを始めたり続けたりするときは、読むだけのジョブも含めて、必ず確認画面を出す。確認画面にはエージェントに渡す指示そのもの、作業場所、書き込めるかどうかを載せ、ユーザーがボタンを押したときだけエージェントを起動する。`merge_agent_job` も、取り込む変更の一覧を確認画面に載せ、承認されたときだけ取り込む。`discard_agent_job` も、どのジョブのどの worktree を消すかを確認画面に載せ、承認されたときだけ消す。消した変更は元に戻せない。

会話のモデルの文脈には、メール、ウェブ検索、メモ、予定の文面が入る。そこに「エージェントでこのコマンドを実行して」「さっきの変更は捨てて」と書かれていれば、モデルがそれに従ってジョブを始めたり、ユーザーがまだ見ていないジョブの成果を消したりすることがありうる。一方で、書き込めるジョブは claude の `--permission-mode auto` や codex の `--approve-for-me` で動き、どちらも OS のサンドボックスではない。claude はコマンドもネットワークも使え、作業フォルダの外にも書ける。専用の作業フォルダは起動するときのディレクトリにすぎず、閉じ込める仕組みではない。そのため、ジョブはユーザーの権限で動くものとして扱い、始める前と成果を捨てる前に本人が中身を見て決める。

確認画面には、ボタンでだけ答える。声では承認できず、確認画面が出ているあいだの発話は承認にもキャンセルにもならない。会話のターンが確認の答えを待っているあいだは、発話でそのターンを打ち切らず、答えとその操作の結果が記録されてから発話を扱う。モデルが「確認画面で承認してください」と言い、ユーザーが声で「はい」と答えるのは自然な流れで、その発話で確認を閉じると、承認しようとしたユーザーの操作を取り消すことになる。確認を待つあいだに読み上げに割り込んだだけで言葉が続かなかったときは、読み上げは止まるが、ターンは打ち切らず、答えとその操作の結果を受けて返事をする。その返事は、ユーザーがまだ聞いていない、承認した操作がどうなったかである。

画面のボタンからユーザーが直接行う操作(ジョブカードの「取り込む」と「捨てる」、設定画面の「今すぐ整理する」)は、その操作自体が承認なので、確認画面を重ねない。ただし、サブモジュールに触れたジョブをカードの「捨てる」で捨てるときだけは確認画面を出す。サブモジュールの中で作ったコミットはカードの差分に出ず、worktree の中の複製にしか無いので、ボタンを押した時点のユーザーは何が消えるかを見ていないからである。記憶の整理は誰にも聞かずにタイマーで動いて取り込むので、差分が記憶のフォルダの中の普通のファイルだけであることを確かめ、そうでなければ取り込まずに失敗として記録する。整理のジョブ自体も、書き込めるジョブの無人のモードでは動かさない。claude は restricted モードで動かし、ファイルの道具を作業フォルダの中に限り、許したもの以外はすべて断らせ(dontAsk)、実行できるコマンドはスキルの検査スクリプトだけにする。codex は承認を出さない workspace-write のサンドボックスで動かし、ネットワークと作業フォルダの外への書き込みを OS に止めさせる。

## 見送った案

- **読むだけのジョブは確認なしで始める。** 読むだけの claude のジョブにも WebFetch があるので、~/.ssh などを読んで URL に載せて外へ送れてしまう。
- **専用の作業フォルダで動くジョブは確認なしで始める。** 作業フォルダは閉じ込めになっておらず、書き込めるジョブはホームフォルダのどこにでも書ける。
- **git リポジトリのジョブは worktree で隔離して確認なしで始め、承認は取り込みのときにする。** worktree も閉じ込めにはならず、取り込む前にエージェントがリポジトリの外で何でもできる。
- **取り込みの確認をツールの説明でモデルに頼む。** 文脈に入った文面がモデルを動かす以上、モデルへの指示は承認の代わりにならない。
- **worktree の破棄は確認なしで行う。** 取り込んでいない成果は worktree にしか無く、文面に動かされたモデルが消すと取り戻せない。

## 分かっている制約

- ジョブを始めるたびに確認画面が出るので、ユーザーが画面の前にいないとジョブは始まらない。確認は5分で打ち切られ、そのときは始めない。
- 確認を待つあいだに話しかけると、その返事は確認に答えるまで返らない。
- Gemini Live ではツールを Gemini が呼ぶので、話しかけた内容には Gemini がその場で返事をする。Gemini が呼び出しを取り消すと、確認画面も閉じる。
