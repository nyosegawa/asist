# メモはユーザーの文書として扱い、会話の Agent には新しく書くことと読むことしかさせない

メモは1件を1つの Markdown ファイルにして `userData/notes/` に置く。会話の Agent が使えるツールは、新しいメモを書く `add_note`、探す `search_notes`、読む `read_note` だけで、既存のメモを書き換えることも消すこともできない。書き換えと削除はメモの画面で行い、削除は確認のあとでファイルを macOS のゴミ箱に移す。

記憶は整理の Agent が書いて会話に添えるものだが、メモはユーザーが書いて残す文書であり、ユーザーの知らないうちに中身が変わってはいけないからである。同じ理由で、メモは毎回の会話に載せず、必要なときにツールで読む。

## 見送った案

- **既存のメモの末尾に Agent が追記するツール(`append_note`)。** 全体の上書きはさせない形でも、ユーザーの文書を Agent が変えることになるので入れない。
- **会話からメモを消すツール。** 記憶と同じく、消すのは画面で足りる。
- **メモを記憶の一部にする。** 記憶は整理の Agent が書き換えるので、ユーザーの文書の置き場所に向かない。
