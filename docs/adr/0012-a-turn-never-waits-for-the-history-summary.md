# 会話のターンは履歴の要約を待たず、文脈が API の上限に近いときは答えずにそう伝える

履歴の要約は長い会話を読んで最大 8,192 トークンを書くので、数分かかることがあり、失敗することもある。会話のターンはこの要約を待たない。文脈が 20 万トークンを超えると、要約はターンの前に始まり、ターンはそのときの履歴で送る。API の上限に近い 80 万トークンを超えたときは、要約が済むまでターンを送らず、いま要約しているので少ししてから話しかけてほしいと話して終える。要約はそのあいだも裏で続き、失敗したときは次のターンがまた始める。ジョブの報告はこの文で届いたことにならないように、要約が済むまで始めない。

## 見送った案

- **上限に近いときは、ターンが要約の終わりを待つ。** 要約のあいだ数分黙り、要約が失敗するたびに次のターンもまた待つ。ジョブの報告は再生を待つ時間を過ぎて届かなかったものとされ、送り直されて同じ報告を何度も話す。
- **古いターンを削って送る。** 答えは返るが、前の話を忘れたことが利用者に分からない。黙って質を落とすことになる。

## 分かっている制約

- 要約が失敗し続けるあいだ、文脈が上限に近い会話には答えられない。
