The first time you open ASIST, you go through nine screens in order. Screens that your way of talking does not need are skipped. At the bottom of each screen, one line tells you what to do next.

<Steps>

1. **Choose a language**

   Choose one of 11 languages. Your system language is selected at first. The language you choose becomes the starting value for three things: the language of the interface, the language of the conversation, and the region. The screens that follow appear in that language. You can change each of the three separately in the settings later.

   ![The screen for choosing a language](/screens/en/setup-1-language.webp)

2. **Read what to know before you use it**

   Four points appear: answers can be wrong, changes happen only after you approve them, each provider bills you for API use, and the conversation goes to the providers you chose. Once you have read them, tick "I have read and understood these four points" to go on. [Using ASIST safely](/en/docs/start/safety/) explains them in full. If you finished the setup before this screen existed, the same points appear once the next time you open ASIST.

   ![The screen with what to know before you use ASIST](/screens/en/setup-safety.webp)

3. **Enter an API key for the conversation model**

   Choose a provider, enter your API key and click "Verify and save". ASIST checks the key by actually sending a request, and saves it only when it works. The conversation uses the provider's standard model, and the bridge phrase uses a light, fast model. You can change both in the settings later.

   ![The screen after the API key was verified and saved](/screens/en/setup-2-model.webp)

4. **Choose how you talk**

   Choose "Talk by voice", "Type, and hear the replies" or "Text only".

   ![The screen with "Talk by voice" chosen](/screens/en/setup-3-speaking.webp)

5. **Prepare the speech recognition model** (when you talk by voice)

   On a Mac, ASIST recommends Qwen3-ASR or Whisper running on MLX, depending on how much memory the Mac has. On Windows, it recommends Qwen3-ASR 1.7B or 0.6B, depending on the memory of the NVIDIA GPU, and the first preparation also downloads the CUDA build of PyTorch (about 2 GB) with the model. Click "Prepare the model" to download the model and run it on your computer. You can also choose Whisper running inside the browser. On Windows without a usable NVIDIA GPU, the reason appears in place of the model, so choose Whisper running inside the browser.

   ![The screen after the recommended model is ready](/screens/en/setup-4-listening.webp)

6. **Choose a voice for reading aloud** (when you hear the replies)

   Only the options that can speak the conversation language appear. For Japanese, these are "macOS voice", Qwen3-TTS, VOICEVOX and AivisSpeech on a Mac, and "Windows voice", VOICEVOX and AivisSpeech on Windows. Qwen3-TTS is on the Mac only, and you can choose it with 16 GB of memory or more; it downloads a model (about 1.9 GB) and runs it on your Mac. If you choose the system's voice, ASIST checks whether a voice for that language is installed, and if not, shows you where in System Settings or Windows Settings to add one.

   ![The screen with reading aloud ready](/screens/en/setup-5-speech.webp)

7. **Allow the microphone** (when you talk by voice)

   Click "Check the microphone". On a Mac, macOS asks for permission to use the microphone; click "Allow". Windows does not ask. ASIST then checks that it actually receives sound.

   ![The screen after the microphone was checked](/screens/en/setup-6-microphone.webp)

   <Aside type="tip">
   If you did not allow it, you can open System Settings or Windows Settings from this screen, or switch to typing. To allow it later, see [Microphone permission](/en/docs/start/microphone/).
   </Aside>

8. **Wait for the other models**

   ASIST prepares the model for searching the memory by meaning. When you talk by voice in Japanese, it also prepares a model that chooses which backchannel to say, and MaAI, which detects when you have finished speaking. For anything that could not be prepared, you can try again or leave it for later. Anything you leave for later is prepared under "Models" in the settings.

   ![The screen after the other models are ready](/screens/en/setup-7-extras.webp)

9. **Review and start**

   Look over your choices and click "Start with these settings".

   ![The screen that reviews your choices](/screens/en/setup-8-summary.webp)

</Steps>

Once ASIST starts, click `MIC OFF` and talk, or type in the input box and send. How to talk to ASIST is covered in [Using ASIST](/en/docs/usage/).

If you want to use Agent jobs, set up [the Agent CLI](/en/docs/start/agent-cli/) next.
