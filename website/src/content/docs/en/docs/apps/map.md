Ask "Show me a map of Tokyo Station", "Find cafés in Ueno" or "How do I get from Hamamatsucho Station to Tokyo Tower?", and ASIST shows a Google Maps card.

The map is Google's Maps Embed API, shown inside the card. Google resolves the place names inside the map, so ASIST receives no addresses or travel times. All ASIST can say in the conversation is that it showed a map. Google's terms don't allow changes to the map's attribution, so the map on the card has no color filter.
