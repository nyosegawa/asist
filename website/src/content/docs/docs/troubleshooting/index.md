title: 困ったとき
description: よくあるつまずきと、その直し方。
---

## マイクが反応しない

- 「システム設定」→「プライバシーとセキュリティ」→「マイク」で、ASIST がオンになっているかを確かめます。オンにしたら、ASIST を開き直します。
- 画面の `MIC OFF` を押して、マイクを入れているかを確かめます。
- 許可の状態がおかしいときは、[許可をやり直す](/docs/start/permissions/#許可をやり直す)の手順で消してから、許可し直します。

## API キーを確かめられない

初回セットアップや設定の「連携」で、キーを確かめられなかったと出るときは、キーを写し間違えていないか、提供元のアカウントに残高や利用枠があるかを確かめます。

![API キーを確かめられなかったときのセットアップの画面](/screens/ja/setup-key-failed.webp)

## 声が出ない

- 読み上げに VOICEVOX か AivisSpeech を選んでいるなら、そのアプリが「アプリケーション」に入っているかを確かめます。見つからないときは、セットアップと設定の「声」に理由が出ます。
- macOS の声を選んでいるなら、会話の言語の声が入っているかを確かめます。無いときは、「システム設定」→「アクセシビリティ」→「読み上げコンテンツ」の「システムの声」から足します。
- 会話の言語を変えたときは、読み上げが macOS の声に切り替わっていることがあります。設定の「声」を見直します。

## Agent のジョブが始まらない

- 設定の「Agent」で選んだエンジン(codex か claude)の CLI が入っていて、認証を済ませているかを確かめます。準備は [Agent の CLI](/docs/start/agent-cli/) にあります。
- claude は API キーで動かします。Claude.ai のサブスクリプションでのサインインは使えません。

## カレンダーやメールがつながらない

[カレンダーをつなぐ](/docs/start/calendar/#うまくつながらないとき)と[メールをつなぐ](/docs/start/mail/#うまくつながらないとき)の「うまくつながらないとき」を見てください。

## 起動したときに、ファイルを読めないと出る

設定などのファイルが、今の ASIST より新しいバージョンの ASIST で書かれているか、壊れています。表示された場所のファイルは、ASIST が手を付けずに残しています。新しいバージョンの ASIST に入れ替えるか、壊れたファイルを直すか、別の場所に移してから開き直します。くわしくは[データの置き場所](/docs/privacy/#設定のファイルのバージョン)にあります。

## 不具合を知らせる

設定の「会話」の「動作ログ」からログのフォルダを開き、その日のファイルを添えて、[GitHub の Issues](https://github.com/nyosegawa/asist/issues) に書いてください。ログのキーやパスワードは伏せてあります。脆弱性は、公開の Issue ではなく [SECURITY.md](https://github.com/nyosegawa/asist/blob/main/SECURITY.md) の手順で知らせてください。
