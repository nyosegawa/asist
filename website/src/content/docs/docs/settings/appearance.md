---
title: 見た目
description: 画面全体のテーマを選ぶ。
sidebar:
  order: 2
---

「見た目」で、画面全体のテーマを 4 つから選びます。選ぶとすぐに切り替わり、色、背景、カードの見出しが変わります。

| テーマ | 見た目 |
|---|---|
| フューチャー | 夜空と青いガラス。最初の見た目です。 |
| シンプル | 明るい白い壁 |
| ポップ | 明るい色と太い線 |
| クール | 暗いコンクリートの部屋 |

天気と時計のカードの絵は、どのテーマでも夜の景色のままです。
