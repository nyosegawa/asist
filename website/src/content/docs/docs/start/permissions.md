ASIST は、声で話すときにマイクを、カレンダーをつなぐときに macOS のカレンダーを使います。どちらも、最初に使うときに macOS が許可を求めます。

## マイク

初回セットアップの「マイクを検証する」で、macOS が許可を求めます。「許可」を押します。

許可しなかったときや、あとから許可するときは、次のようにします。

1. 「システム設定」→「プライバシーとセキュリティ」→「マイク」を開きます。
2. 一覧の ASIST をオンにします。
3. ASIST を終了して、開き直します。

![マイクを許可しなかったときのセットアップの画面](/screens/ja/setup-mic-denied.webp)

## カレンダー

設定の「連携」で「カレンダー連携をオンにする」のスイッチを入れると、macOS がカレンダーへのアクセスを求めます。「フルアクセスを許可」を押します。予定を読むだけでなく、追加、変更、削除もするので、フルアクセスが要ります。

あとから許可するときは、「システム設定」→「プライバシーとセキュリティ」→「カレンダー」で、ASIST を「フルアクセス」にします。ASIST に戻って「一覧を更新」を押します。

つなぎ方の全体は、[Google カレンダー](/docs/integrations/calendar/)にあります。

## 許可をやり直す

一覧に ASIST が出てこないときや、許可の状態がおかしいときは、ターミナルで許可を消してから、ASIST を開き直して許可し直します。

```bash
tccutil reset Microphone com.nyosegawa.asist
tccutil reset Calendar com.nyosegawa.asist
```

macOS は、この許可をアプリの署名に結び付けています。ASIST を配布元の Release 以外から入れ直すと、許可をやり直すことになります。
