## 更新

ASIST は、開いたときと、開いているあいだ 6 時間ごとに、新しいバージョンが出ていないかを GitHub の Release に確かめます。新しいバージョンがあれば裏で取得し、次に ASIST を終了したときに入れ替えます。話している最中やジョブが動いている最中に、勝手に再起動することはありません。

すぐに入れ替えたいときは、設定の「このアプリについて」で「今すぐ再起動」を押します。今のバージョンと更新の状態も、ここに出ます。

出したバージョンに問題があったときは、番号を上げて直したバージョンを出します。前のバージョンに戻す操作はありません。

## アンインストール

1. ASIST を終了します。
2. 「アプリケーション」から ASIST をゴミ箱に入れます。
3. 設定とデータも消すときは、次のフォルダをゴミ箱に入れます。記憶、メモ、タスク、会話の履歴、取り込んだメールも消えます。
   - `~/Library/Application Support/asist/`
   - `~/Library/Logs/asist/`
4. 保存した API キーとメールのパスワードの暗号化に使った鍵を消すときは、「キーチェーンアクセス」で「asist Safe Storage」を探して削除します。
5. マイクとカレンダーの許可も消すときは、ターミナルで次を実行します。

```bash
tccutil reset Microphone com.nyosegawa.asist
tccutil reset Calendar com.nyosegawa.asist
```

データの置き場所の一覧は、[データの置き場所](/docs/privacy/)にあります。
