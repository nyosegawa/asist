声で話すときは、ASIST がマイクを使います。初回セットアップの「マイクを検証する」で、macOS が許可を求めるので、「許可」を押します。

## あとから許可する

許可しなかったときや、あとから許可するときは、次のようにします。

1. 「システム設定」→「プライバシーとセキュリティ」→「マイク」を開きます。
2. 一覧の ASIST をオンにします。
3. ASIST を終了して、開き直します。

![マイクを許可しなかったときのセットアップの画面](/screens/ja/setup-mic-denied.webp)

## 許可をやり直す

一覧に ASIST が出てこないときや、許可の状態がおかしいときは、ターミナルで許可を消してから、ASIST を開き直して許可し直します。

```bash
tccutil reset Microphone com.nyosegawa.asist
```

macOS は、この許可をアプリの署名に結び付けています。ASIST を配布元の Release 以外から入れ直すと、許可をやり直すことになります。

カレンダーの許可は、[カレンダーの接続](/docs/start/calendar/)にあります。
