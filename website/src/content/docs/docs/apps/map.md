title: 地図
description: Google マップのカード。

「東京駅の地図を見せて」「上野のカフェを探して」「浜松町駅から東京タワーまでの行き方」で、Google マップのカードを出します。

地図は、Google の Maps Embed API をカードの中に表示しています。場所の名前は Google が地図の中で解決するので、ASIST は住所や所要時間を受け取りません。会話で話せるのは、地図を出したことだけです。Google の規約で地図の帰属表示を変えられないため、カードの地図には色のフィルターをかけていません。
