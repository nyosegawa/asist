# 사용자

## 기본 정보
사는 곳, 가장 가까운 역, 직장에서의 역할, 가족, 가진 물건 등 잘 바뀌지 않는 사실. 사실 자체가 바뀌었을 때만 이전 값을 한 문장으로 덧붙인다.

## 취향
음식, 음료, 시간을 보내는 방식. 그날 있었던 일이 아니라, 보고 들은 것에서 일반화한 경향을 쓴다. 본인이 말한 것은 단정하고, 추측은 "~인 것 같다"로 표시한다.

## 습관
어느 요일이나 시간대에 무엇을 하는지.

## ASIST에 바라는 점
내 말투와 행동에 대해 사용자가 바라는 것.
